# ADA

Sistema pessoal de organização e produtividade para a web, instalável como Progressive Web App (PWA).

## Funcionalidades

- **Painel de Tarefas e Foco:** acompanhe tarefas e sessões de foco.
- **Calendário:** organize eventos, lembretes e compromissos.
- **Journal:** registre hábitos, notas e atividades do dia.
- **Finanças:** acompanhe contas, transações, orçamentos e metas.
- **Chat com Agentes de IA:** converse com agentes para consultar informações e apoiar sua rotina.

## Rodar localmente

Requisitos: Node.js 22 ou mais recente e npm.

```bash
npm install
npm run dev
```

Abra no navegador o endereço local informado pelo Vite no terminal.

Para gerar a versão de produção:

```bash
npm run build
```
